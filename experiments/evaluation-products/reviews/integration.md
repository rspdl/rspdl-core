## 실행 전에 반영한 수정

- E01-F01: 취소 입력을 반드시 폐기해야 한다는 평가자 전용 조건을 제거했다. 미제출 값을 완료 자료로 취급하지 않는다는 공개 요구만 판정한다. 이후 명시적인 재제출은 금지하지 않는다.
- E01-F02 / E02 / E03: 문법 용어는 소스 검토와 업무 의미의 약칭임을 명시했다. 양쪽 최종 한국어 명세만 판정하며 RSPDL 구문을 요구하거나 중간본으로 누락을 구제하지 않는다.
- E02: 완료 화면의 알림함 복귀는 원래 화면 권한에 따라 교육담당에게만 제공함을 공개 입력에 명확히 했다. 비공개 여정의 예시 이름·날짜·번호를 최종 명세에 그대로 적을 의무가 없다는 공통 평가 지시를 추가했다.
- E03: 현재 없는 조건부 Create 효과를 요구하던 설계를 수정했다. 요청·인계증 준비 생성과 기존 기록의 정정 개시·인계 확정을 구분했다. 생성 출처가 연결되는 실제 문법을 사용하도록 요청종류·인계방식을 명시하고 각 종류에서 하나를 생성한다.
- E03: 사건의 결과별 상수 필드 생산을 요구하지 않고, 공통 문자열 조합과 별도 결과 필드를 사용한다. 서두의 정정 반영 주체, 필드·버튼 수와 대표 여정을 새 요구에 맞춰 수정했다.

위 변경은 생성 모델을 실행하기 전 사례 작성·검토 과정이다. 관측된 낮은 점수를 없애기 위해 기준을 바꾼 것이 아니다. 이후 변경은 실행 버전·영향받는 요구·사유를 따로 남긴다.

## 남겨 둔 분석기 한계

문법으로 표현 가능한 것과 현재 분석기가 충분히 연결해 검사하는 것은 다르다.

- 명시적 `업무.획득`은 같은 버튼의 모든 목적지 경로에 적용될 수 있다. 성공 결과의 `제공 데이터`와 다르며 저장 성공 증명으로 읽으면 안 된다.
- 조건부 생성이 있는 업무는 `WORKFLOW-U001`로 완료 데이터 검사를 보류할 수 있다.
- 외부 초기 자료·조회 결과·typed field producer가 legacy 화면 소비 분석에 연결되지 않아 `DATA-001/002`가 나올 수 있다. 실제 기록을 가짜 사용자 입력이나 생성 화면으로 바꾸지 않는다.
- 통합 statement는 compile-only다. 조건별 권한 집행·저장·복구 성공은 컴파일 통과로 증명하지 않는다.

E03의 초기 검토에는 화면 소비를 설명문으로 우회하는 대안이 있었다. 최종 통합에서는 **최종 한국어 명세의 표현 자유**와 **C 중간본의 구조적 의도 보존**을 구분했다. 지원 문법으로 표현 가능한 요구를 지워 진단을 없애는 것은 개선 성과로 세지 않는다. 실제 진단은 보존하고, 원인을 확인해 다음 코드·품질 개선 대상으로 삼는다. 도구 결과와 최종 업무 의미 점수는 따로 보고한다.

개별 검토 기록은 당시 발견 사항을 보존하므로 `수정 필요`라는 최초 표현이 남아 있을 수 있다. 위 항목은 루트의 반영 기록이며 해당 검토자가 수정 뒤 재승인했다고 대신 주장하지 않는다. 현재 파일 해시는 내용 manifest에 남긴다.

## 검증의 범위

소스·conformance 자료를 읽어 표현 범위를 검토하고, 공개 요구와 평가표·예시의 일치를 검토했다. 파일 ID·개수·링크 검사는 문서 정합성 확인일 뿐 제품 동작이나 모델 성능의 검증이 아니다. 정답 RSPDL·테스트 코드·실행기는 추가하지 않았다. 생성 모델, 실제 제품, compiler를 실행해 이 제품이 동작한다고 확인한 상태가 아니다.

최종 파일 검사에서 E01 35개, E02 42개, E03 42개 공개 ID가 각 평가표와 일치했고 제품별 여정 3개와 Markdown 링크 연결을 확인했다. 지식 문서 index를 재생성하고 metadata 검증을 통과했다. 작성 작업 폴더에서는 기존 개발용 평가기까지 포함한 Python 검사 48개를 확인했다. 평가 자료만 분리한 PR 브랜치에서 전체 harness를 다시 실행했을 때는 해당 브랜치의 기존 Python 검사 14개와 release metadata 확인을 통과한 뒤 `cargo: command not found`로 중단됐다. 따라서 Rust/compiler 검증을 통과했다고 보고하지 않는다. 이 기존 검사 결과는 새 평가 사례의 점수나 업무 정확도의 증거로 사용하지 않는다.
