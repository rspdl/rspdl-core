# 실행 전·후 기록 양식

이 파일은 양식이며 실행 기록이 아니다. 미기입 항목을 채우고 사본을 실행별로 보관한다.

## 실행 전에 고정

- 실행 ID / 계획 일시 / 담당자:
- 입력·공통 계약·프롬프트·평가기준 버전과 해시:
- RSPDL git SHA / 미커밋 변경 유무 / 실행 바이너리·패키지 버전:
- 생성 모델 ID / 정확한 revision / 양자화 / 런타임 버전:
- Sol 평가 모델 식별자 / 추론 설정:
- 생성 temperature / top_p 등 실제 지원 옵션:
- seed 3개 또는 seed 미지원 사유와 반복 번호:
- 제품별 B/C 실행 순서:
- 문맥 상한 / 호출별 출력 상한 / 총 호출 수(기본 3):
- 입력 tokenizer 측정 결과와 개발용 자료에서의 예산 확인:
- C에 제공하는 문법 자료 목록·해시 / 실제 도구 명령 / 도구 시간 제한:
- 하드웨어 / 네트워크 및 도구 실행 가능 여부:
- 익명 후보 ID와 방식의 대응표 보관 위치(평가자에게 비공개):

## 실행 후 기록

- 제품 ID / 반복 번호 / 익명 후보 ID:
- 원시 요청·응답·최종 명세·중간 산출물 경로:
- 호출별 입력·출력 토큰 / 소요 시간 / 종료 이유·잘림 여부:
- 실제 도구 요청·진단 원문 / exit code / 시간:
- 인프라 실패·재시도 여부와 사유:
- 최초 Sol 평가 / 사람 확인 내역 / 확정 또는 잠정 여부:
- 요구사항 전체 N / 충족 P / 위반 F / 보류 U (`P+F+U=N`):
- 중요 위반 ID / 여정 3개 판정 / 모순·과도한 주장:
- 동일 반복 B/C 대응 차이와 전체 요약에 포함되는지:
- 평가 중 발견한 기준 결함 / 변경 없이 기록한 한계:

개선 실험은 위 기록을 덮어쓰지 않고 새 실행 ID와 변경 이유를 가진다.
